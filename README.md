| Metric        | Meaning                                                  |
| ------------- | -------------------------------------------------------- |
| **Precision** | How many retrieved documents were actually relevant      |
| **Recall**    | How many relevant documents were successfully retrieved  |
| **F-measure** | Harmonic mean of precision and recall (balance)          |
| **E-measure** | Error-based version of F-measure                         |
| **NDCG**      | Measures ranking quality (higher score = better ranking) |
